# Student Management System

A simple and basic Student Management System built using MySQL to store, manage, and organize student records efficiently.

## Features
- Store student personal details (Name, ID)
- Track academic information (Department, Campus, Semester)
- Basic SQL queries for database management

## Technologies Used
- MySQL
- SQL

## Getting Started
1. Clone the repository.
2. Run the SQL script (`database/`) in your MySQL server or database workbench to create the table and insert sample records.
